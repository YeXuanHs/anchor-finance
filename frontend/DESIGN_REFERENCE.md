## 一、设计总纲

### 1.1 技术栈
| 项目 | 技术选型 |
|------|----------|
| **用户前台** | Vue 3 + TypeScript + Vite |
| **管理后台** | Nuxt 4.0 + TypeScript |
| **UI组件库** | Element Plus |
| **状态管理** | Pinia |
| **图表** | ECharts |
| **图标** | @element-plus/icons-vue + 自定义SVG |

### 1.2 设计原则
- **蓝色双色调**: 深蓝 `#1a3a5c` + 浅蓝 `#0056FF` 为主色
- **圆角**: 统一 `8px` 圆角（按钮 `6px`，卡片 `12px`）
- **骨架屏 + 加载动画**: 页面级用骨架屏，按钮/局部用旋转圈
- **渐变**: 按钮和强调区域使用蓝色渐变
- **阴影**: 轻微阴影 `0 2px 12px rgba(0,0,0,0.08)`

## 二、配色方案

### 2.1 主色调
```scss
// 深蓝系
$primary-dark:    #1a3a5c;    // 深蓝（header/sidebar背景）
$primary:         #0056FF;    // 主蓝（按钮/链接/强调色）
$primary-light:   #4080FF;    // 浅蓝（悬停/辅助）
$primary-lighter: #EBF3FD;    // 极浅蓝（背景/卡片高亮）

// 渐变
$gradient-primary: linear-gradient(135deg, #1a3a5c 0%, #0056FF 100%);
$gradient-button:  linear-gradient(135deg, #0056FF 0%, #4080FF 100%);
$gradient-hero:    linear-gradient(135deg, #0c1a36 0%, #1a3a5c 50%, #0056FF 100%);
```

### 2.2 功能色
```scss
$success:   #3fbf70;    // 成功/运行中
$warning:   #fca426;    // 警告/待处理
$danger:    #e31519;    // 错误/已暂停
$info:      #909399;    // 信息/禁用

$text-primary:   #202d40;    // 主文字
$text-regular:   #606266;    // 常规文字
$text-secondary: #909399;    // 辅助文字
$text-placeholder: #C0C4CC;  // 占位文字

$bg-page:    #f5f7fa;    // 页面背景
$bg-card:    #ffffff;    // 卡片背景
$bg-sidebar: #1a3a5c;    // 侧边栏背景
$bg-header:  #1a3a5c;    // 顶部导航背景
$bg-footer:  #0c1a36;    // 底部背景

$border-base:    #DCDFE6;    // 边框
$border-light:   #E4E7ED;    // 轻边框
$border-lighter: #EBEEF5;    // 更轻边框
```

### 2.3 色彩使用规范
| 场景 | 颜色 |
|------|------|
| 主按钮 | 蓝色渐变 `$gradient-button` |
| 次按钮 | 白色底 + 蓝色边框 |
| 成功状态 | `$success` 绿色 |
| 警告状态 | `$warning` 橙色 |
| 错误状态 | `$danger` 红色 |
| Header/侧边栏 | 深蓝 `$primary-dark` |
| 页面背景 | 浅灰 `$bg-page` |
| 卡片背景 | 白色 `$bg-card` |
| 链接 | `$primary` 蓝色 |

### 4.5 骨架屏设计

**页面级骨架屏**（首次加载）：
```vue
<!-- 使用 el-skeleton -->
<el-skeleton :rows="10" animated>
  <template #template>
    <el-skeleton-item variant="h1" style="width: 40%" />
    <el-skeleton-item variant="text" />
    <el-skeleton-item variant="text" />
    <el-skeleton-item variant="rect" style="height: 200px" />
  </template>
</el-skeleton>
```

**卡片级骨架屏**（局部刷新）：
```vue
<el-card v-loading="loading" element-loading-text="加载中...">
  <!-- 内容 -->
</el-card>
```

**按钮加载态**：
```vue
<el-button type="primary" :loading="submitting">
  {{ submitting ? '提交中...' : '提交订单' }}
</el-button>
```

## 六、动画规范

### 6.1 骨架屏动画
- 使用 Element Plus 内置的 `el-skeleton` 组件
- `animated` 属性启用波浪动画
- 背景色: `#f2f2f2` → `#e6e6e6` 循环

### 6.2 页面过渡
```vue
<!-- 路由过渡动画 -->
<router-view v-slot="{ Component }">
  <transition name="fade-slide" mode="out-in">
    <component :is="Component" />
  </transition>
</router-view>
```

```scss
.fade-slide-enter-active,
.fade-slide-leave-active {
  transition: all 0.3s ease;
}
.fade-slide-enter-from {
  opacity: 0;
  transform: translateY(20px);
}
.fade-slide-leave-to {
  opacity: 0;
  transform: translateY(-20px);
}
```

### 6.3 加载状态
- **全页加载**: 骨架屏 + 渐入动画
- **按钮加载**: `el-button` 的 `loading` 属性 + 旋转图标
- **表格加载**: `v-loading` 指令
- **卡片加载**: `el-skeleton` 嵌套在 `el-card` 内
